# Co miał robić minutnik

## Co robi

1. Program pozwala uruchomić odliczanie dwudziestu pięciu minut pracy.
2. Program pozwala wstrzymać i wznowić bieżące odliczanie.
3. Program po zakończeniu pracy automatycznie rozpoczyna przerwę.
4. Program pokazuje po cztery cykle pracy krótką lub długą przerwę.
5. Program pozwala zresetować bieżący etap do dwudziestu pięciu minut pracy.
6. Program pokazuje bieżący etap i numer licznika cykli.

## Czego nie robi

1. Nie zapisuje historii sesji ani czasu po zamknięciu aplikacji.
2. Nie odtwarza dźwięku ani powiadomień systemowych.
3. Nie synchronizuje czasu między urządzeniami.
4. Nie pozwala zmieniać długości etapów podczas odliczania.

## Po czym poznam

1. Kiedy uruchomię aplikację, to zobaczę 25:00 i etap „Praca”.
2. Kiedy kliknę Start, to czas zacznie odliczać sekundy.
3. Kiedy zakończy się dwadzieścia pięć minut pracy, to przerwa zacznie się bez klikania.
4. Kiedy naciśnę Pauza, to licznik zatrzyma się i nie zmieni czasu.
5. Kiedy naciśnę Reset, to licznik wróci do 25:00 i pokaże etap „Praca”.

## Do ustalenia

1. Czas trwania długiej i krótkiej przerwy został przyjęty jako 5 i 15 minut.
2. Reset w środku przerwy ma zostawić licznika cykli bez zmian i rozpocząć etap pracy od 25:00.
3. Wznowienie po pauzie ma kontynuować ten sam etap od pozostałego czasu.
